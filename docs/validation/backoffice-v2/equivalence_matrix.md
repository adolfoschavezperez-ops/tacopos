## 2. Propuesta de esquema para persistencia de Metas de Eficiencia y Presupuestos Semanales (Pendiente de aprobación)

- **Colecciones propuestas** (aisladas por `restaurantId` y `branchId`, sin impacto en POS Android):
  - `restaurants/{restaurantId}/backofficePurchaseTargets/{branchId}_{categoryKey}`: `{ restaurantId, branchId, category, targetPer100Sales, updatedAt, updatedByEmployeeId, updatedByEmployeeName }`.
  - `restaurants/{restaurantId}/backofficePurchaseBudgets/{branchId}_{purchaseItemId}`: `{ restaurantId, branchId, purchaseItemId, itemName, unit, targetWeeklyQty, updatedAt, updatedByEmployeeId, updatedByEmployeeName }`.
- **Seguridad propuesta**: lectura para `canReadPurchases(restaurantId) && canAccessBranch(restaurantId, branchId)`; escritura exclusiva para `canManageSuppliersCatalog(restaurantId) && canAccessBranch(restaurantId, branchId)`.
- **Compatibilidad**: 100% aditivo; Android ignora estas colecciones y nunca bloquea ventas.
